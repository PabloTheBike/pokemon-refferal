# Pokémon Referral Site

Update `config.js` to change the referral link.

## Publish

Go to **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**, and Save.

Public site: https://pablothebike.github.io/pokemon-refferal/

## Update the link

Edit `config.js` on GitHub. Replace the empty `url` with your full https:// referral link, then commit. The public page will update after deployment.

Your GitHub login protects editing. There is no separate admin dashboard; the public URL and website code are visible to visitors.
